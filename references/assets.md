# Built-in assets

Every texture, prop and character the renderer draws, by name: what each one is and how it is best used. How to put them in a scene is in `scene_format.md` (Textures, Sprites); `python scripts/assets.py catalog.png` draws them all on one sheet, and `docs/ASSETS.md` keeps the review notes.
